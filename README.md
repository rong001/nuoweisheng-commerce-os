# 诺维生 Commerce OS

面向多平台电商的 AI 经营工作台演示系统，围绕统一商品与订单、库存协同、流程自动化和业务决策构建。

**[打开 Commerce OS](https://rong001.github.io/nuoweisheng-commerce-os/)**

本仓库存放预构建的单文件网站，可由 GitHub Pages 直接发布。页面已内联脚本、样式及品牌图片，无需额外 CDN。

## 18 个业务模块

| 业务分组 | 功能模块 |
| --- | --- |
| 工作台 | 经营总览、待办中心 |
| 商品与渠道 | 商品中心、渠道商品、内容工作台 |
| 交易与服务 | 订单中心、售后工作台、客户档案 |
| 供应链 | 库存中心、采购补货、供应商 |
| 经营决策 | 竞争情报、利润分析、智能决策 |
| 流程与治理 | 自动化编排、审批中心、操作审计、系统设置 |

## 3 种界面 × 3 个业务空间

- **界面风格**：云白、石墨、午夜。共享同一套完整业务功能。
- **业务空间**：稳态经营、增长备货、利润优化。各自拥有独立演示账本及操作进度。
- **演示角色**：运营专员、业务负责人、只读观察。用于展示提交、审批和查看的职责边界。

## 可演示的业务联动

- 竞品价差 → 利润底线检查 → 调价申请 → 审批执行 → 版本校验与回滚。
- 库存预警 → 采购申请 → 采购在途 → 分批收货 → 可售库存更新。
- 订单占库 → 发货或取消 → 库存释放；退货验收与退款进一步影响库存和利润。
- 渠道上下架、商品文案检查 → 审批发布 → 变更记录。
- 规则巡检与经营分析 → 具体业务任务 → 审批、执行和审计。

经营指标从当前演示账本计算，操作结果会联动订单、库存、采购、售后及利润视图。

## 数据与能力边界

所有商品、客户、订单、竞品报价和经营数据均为**合成演示数据**，不代表公司的真实内部经营情况。
五个渠道的连接、调价、上架、采购、发货和退款均为模拟操作，不会触达真实平台。

业务状态保存在当前浏览器的 **localStorage**；各业务空间独立保存，不同浏览器或设备不共享进度。
角色切换仅用于演示，**没有服务端身份认证**，请勿输入真实客户信息或平台密钥。

“智能决策”和内容建议采用本地业务规则及模板，没有调用外部大模型，也不是实时竞品采集或真实 RAG 服务。

## 源码 ZIP 使用说明

完整源码：[下载 source-v2.zip](./source-v2.zip)。本地交付包中的同一份文件名为 `诺维生-Commerce-OS-v2-源码.zip`。
本仓库根目录是可直接发布的静态产物；开发及自验请先解压源码 ZIP，进入其中的 `nuowei-commerce/`。

需要 Node.js 22.13 或更新版本：

```sh
npm ci --include=dev --include=optional
npm run test:business
npm run dev:pages
```

业务自验包含 350 条断言。开发地址为 `http://127.0.0.1:4173`。

```sh
npm run build:pages
npm run package:portable
```

构建产物位于 `dist-pages/`，单文件发布材料位于 `work/github-upload/`。
源码保留的原 Worker/API 工程尚未连接 v2 的业务操作；当前公开演示使用浏览器本地状态。
源码包不包含依赖目录、运行数据或凭据，原托管项目标识已替换为占位值。
